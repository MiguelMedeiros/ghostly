section: Fixed / Web app
---
- A link in a contact's shared app that opens in a new tab (`target="_blank"`, `window.open`, or a new window by name such as `target="_new"`) opens again: tapped, a link to another website opens in a new tab of the browser, as Desktop opens it in the system browser. Before, it did nothing and said nothing. Only a tap or a key in the app itself opens one: not the tap on Open that starts the app, nor one in Ghostly around it. A link asked for within 5 seconds of those (Enter on the app's first link right after the Tab into it) is offered on an "Open <site>" button in the app's bar, and a tap there opens it. A site's name too long for the button is cut at its start, as the browser's address bar does, so its end (`…example.net`) stays on screen. Links to this device or the local network still open nowhere.
