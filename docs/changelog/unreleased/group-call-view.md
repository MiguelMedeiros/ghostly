section: For developers / Calls

- The group call window is in the web UI, not reachable yet: a grid of everyone in the call with the active speaker ringed, a shared screen large with the faces beside it, mute, camera, share screen and leave, and a small window when you go back to the chat list. Leaving the call gives the keyboard focus back to what opened it. A group shows it once its node turns group calls on. Whether it is small, and where and how big, is this device's choice, as for a 1:1 call: Clear all data of one profile keeps it, and a backup or move of a profile does not carry it.
