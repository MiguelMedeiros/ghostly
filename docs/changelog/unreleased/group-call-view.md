- The group call window is in the web UI, not reachable yet: a grid of everyone in the call with the active speaker ringed, a shared screen large with the faces beside it, mute, camera, share screen and leave, and a small window when you go back to the chat list. Leaving the call gives the keyboard focus back to what opened it. A group shows it once its node turns group calls on.
