- With Hide my IP from contacts on, the Desktop app looks up and publishes chat records through the Pkarr relays only and sends nothing to the DHT's nodes, so a contact who runs DHT nodes cannot see this computer asking for your chats. Settings, Network shows "Also use Pkarr relays" as on while it is. Turned off, the app reads the DHT directly again.
