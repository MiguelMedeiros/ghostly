- Behind the apps flag: an app granted `name` now gets the person's name in `context()` on the web app and on Desktop. It is the name the profile tells that chat's contact, so Chess can show who plays. There is no name while the profile has none or does not share it, before the contact was first heard from in that chat, and when the app is opened alone.
