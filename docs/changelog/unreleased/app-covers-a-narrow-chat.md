- On a tablet held upright or in a narrow window, an app opened in a chat now covers the chat, with Back to it, when there is no room for both. Before, it sat beside the chat and squeezed it: on an iPad with the chat list open the chat was 40 px wide (none at 768 px), and at 1024 px its name was gone and the message field was 84 px. Escape there goes Back to the chat, and closes an app that stopped.
