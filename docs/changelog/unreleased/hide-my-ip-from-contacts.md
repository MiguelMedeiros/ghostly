- Hide my IP from contacts, in Settings, Network: calls, chat connections and group links go through your own TURN server only, so contacts see its address and never yours. It needs a TURN server. If the server does not answer, a call fails with "Your relay did not answer" and a chat waits for the DHT; nothing falls back to a direct connection. On the desktop, Iroh and HyperDHT connections that would show your address are not used while it is on, and calls in the Linux app are off.
