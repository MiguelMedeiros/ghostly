- A store's Refresh on the Apps page that works now says so, with the number of apps the store lists ("Hunt is up to date: 5 apps"), and a screen reader reads it out. The store's name keeps its own direction in that line, so an Arabic store's name in English, or a name ending in "!" in Arabic, reads in the right order. Before, only a Refresh that failed said anything: one that worked changed the count and took the red line away without a word. A store whose list is past its date says it is out of date since then, as the line under it does, never that it is up to date.
