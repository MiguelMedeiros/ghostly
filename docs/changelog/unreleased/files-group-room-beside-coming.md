- Group files fetched by themselves are no longer fetched past the free space on this device when several come at once, or while a file from a chat is still on its way: each is checked beside the files still coming, group and chat alike. The ones that fit come; the rest wait for you to tap Download, instead of being asked for and then failing with "Not enough space". A file offered in a chat while group files are still coming is likewise asked about when it fits only without them.
