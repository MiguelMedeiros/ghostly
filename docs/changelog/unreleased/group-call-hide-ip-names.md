- With Hide my IP from contacts on, Join call asks once before the group's node sees this device's IP, then sends the call through the node's TURN relay alone; a node that gives no relay leaves Join call off, saying why. Each person in the group call is named as the group knows them, told apart from a same-named member by the end of their key, and someone outside the group is said to be so, whatever name the node gave.
