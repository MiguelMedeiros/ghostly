- `ghostly task remove <chat|group> <task>` takes a task card you sent off every member's device, Desktop, phone and CLI, not only this one: the card goes as its message's last edit, so a contact or a member who was away gets it when they are back. `--all` removes every task card of yours there, and `routine remove` does the same for routines. Only the author can remove a card; an older app shows "🗑 Message removed" in its place.
