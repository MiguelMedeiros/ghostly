The author of a message can delete it for everyone: a text, a status card, a file or a voice message, in a 1:1 chat or a group. A removal is the author's last edit of the message flagged `rm: true`, so it is authenticated, ordered, sent again and caught up as an edit is, never on the DHT floor; its number may be one past the message's bound (at most 5,001). A reader forgets the message as a delete here does (no text, card, preview, file or reaction) and keeps its id among the chat's deleted ids (the newest 500), so a late copy or another edit brings nothing back; it does so at once for a removal whose message is not here yet. An older app shows the edit's fallback text, `🗑 Message removed`.
