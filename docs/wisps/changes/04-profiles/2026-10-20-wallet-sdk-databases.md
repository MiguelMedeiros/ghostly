Slice 10 of the encrypted profile: what each wallet SDK's own database keeps, read from the pinned builds, and the decision per SDK. Arkade, Bark and Breez keep no phrase and nothing that spends, so their databases stay as the SDK writes them and open only after unlock. Fedimint's file holds the phrase and spendable ecash in the clear, so it is wrapped by a page layer at the file handle, proposed here for the owner's approval (Encrypted profile).
