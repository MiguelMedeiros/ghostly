Slice 5 is built in the engine: given where the profile's wrapped key record is kept (`NodeOptions.profileKey`), `start()` waits for the `unlockProfile` call before it reads any store, connects, polls, reads the DHT or opens a wallet; a wrong passphrase reads nothing and the start keeps waiting; every other call waits with it. A stopped engine drops the data key. The web app, Desktop and the extension pass their record (the local key) with the prompt in slice 6 (Encrypted profile).
