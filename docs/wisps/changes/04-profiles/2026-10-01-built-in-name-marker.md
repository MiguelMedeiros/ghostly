Registry: only a restored name the backup marks as the built-in one (`profile.builtIn`, WISP 05) follows the app's language; a name the user gave is kept as written, even when it is the default profile's name in some language (`Pessoal`). A backup with no marker is read by its own language: built-in only when its name is `"Personal"` or the default profile's name in the language of the backup's settings.
