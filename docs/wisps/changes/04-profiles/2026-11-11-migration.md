Slice 4 is built (`engine/profileEncryption.ts`): turning encryption on and off and changing the passphrase, behind a record home each client provides (its local key, the CLI's file). The `migrating` and `decrypting` marks are kept in the profile's settings sealed under the data key, so a copy that can write the profile cannot make it accept unsealed values again; on, the mark goes before the wrapped key record, and off removes the record before the mark, so neither is ever left alone in a state that locks or exposes data. Turning it on is refused while a Fedimint wallet has a federation, and a federation is not joined or restored while the data key is set. No client calls it yet (Encrypted profile).
