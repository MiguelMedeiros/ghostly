A session message is text (a JSON frame, as before) or binary: a binary message starts with its kind and belongs to the capability that defines it (`0x04`, a file's data under `files/4`, 501). Whether an adapter carries binary messages is its own property: WebRTC does, Iroh and HyperDHT carry text only today, so a capability that needs them is offered only where the adapter carries them. A receiver drops a binary message it does not know.
