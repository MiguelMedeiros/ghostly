Client policy, no wire change: "live when the app last ran" now ends. A run that lasts past the contact's liveness bound (a minute) with the chat never live again writes that the stretch is over into the chat's history, so the next start does not resume it and knock. Before, a chat whose contact never came back stayed "live at last run" at every start, run after run, and knocked each time (all ten chats of the #966 repro). The history shows it as one line ("Live connection not back after this app restarted"); the timeline adds no row.
