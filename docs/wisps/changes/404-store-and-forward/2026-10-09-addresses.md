A reader holds the manifest URL of a pointer to the rule an item URL already had, and the rule is narrower: `https` only, no user or password, at a host name or a public IPv4 address, and no redirect followed. A pointer whose manifest URL fails it is not read; a manifest listing an item URL that fails it is refused whole. Until 1.1.7 the manifest URL was only bounded in length, and an item URL could also be plain `http` to the reader's own machine. A sender whose storage answers on `https` at a public name, as [1002](1002-s3-storage.md) expects, sees no change. No wire change.
