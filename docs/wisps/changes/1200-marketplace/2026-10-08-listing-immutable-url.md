Every store listing must now carry at least one immutable URL, a jsDelivr URL at a full commit (for a bundle the store hosts, the store repository's own commit), and a store's check refuses a listing without one. Since a client installs only the listed digest, a listing whose only URL is a raw `HEAD` stops being installable as soon as that repository moves on, which happens in every window between a merge and the next signed index. Clients read a listing's jsDelivr URLs before its other URLs, so they do not download a bundle of up to 16 MiB only to skip it.
