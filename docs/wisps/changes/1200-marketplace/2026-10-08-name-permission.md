Permissions now says which name the `name` permission gives: the one the person's profile tells the contact of that chat (`paired-nick`, WISP 401), as the contact's app keeps it, read when the app opens. `context()` has no `name` while the profile tells contacts no name (it has none, or its name and picture are not shared), before the contact was first heard from in that chat, and when the app is opened alone. It is never the name of an identity shared in the chat, and never what the contact chose to show on their own device, so an app never learns a name the contact was not told. The web app and Desktop now give it; before, an app granted `name` got none.
