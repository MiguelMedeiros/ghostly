Read lane limits: a request answered whole counts only the bytes the file held from its offset, not the length asked; a cancelled one still counts as the read it started. The asker cuts a read of a serve to the size its last `ar-end` said, and an app hears the server's `busy` as `too-fast`. Small files read at remote.read's 1 MiB length were refused from the 33rd in a second, the app having moved about 1 MiB.
