The broker now stops an app that sends ten times the request rate: more than 500 messages within one second. Past 50 a second a request is still refused with `too-fast`, as before; an app far beyond that is stopped as one that broke the protocol, and on the web its port is closed and its frame removed, so the page receives nothing more from it. Desktop already drops requests over the rate in Rust before the Ghostly window sees them. The Threats row for the broker says so.
