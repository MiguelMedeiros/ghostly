On Desktop, the runner's `activity` now counts for the lock screen only within 2 seconds of a tap or key the system gave the app window's webview itself: GTK's `button-press-event`, `key-press-event` or `touch-event` on Linux, an AppKit mouse-down or key-down for that window on macOS. The app runs in the runner's realm and can call `app_broker` with `activity` itself, so with the window's focus alone as the check, an app left in front with no one there kept the lock away for as long as it ran. Without that input, `app_broker` answers the `activity` itself and the client's window never hears it.
