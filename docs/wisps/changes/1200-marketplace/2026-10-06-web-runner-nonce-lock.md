The web runner and broker were built and measured with a malicious app in Chromium 145, Firefox 155 and Playwright's WebKit 26, against local listeners and a control with no runner that reached 64 to 66 of the probes. Under the runner's header alone, a `srcdoc` frame the app makes had its own `RTCPeerConnection` and reached STUN and TURN in all three engines, and the CSP `webrtc` directive is not recognised by any of them. The runner now locks its page with a nonce: a second policy, `script-src 'nonce-N' 'wasm-unsafe-eval'`, from a `<meta>` it removes at once, with N kept only in its script and set through the `nonce` property. It deletes that property's accessors, `originalPolicy` and `ReportingObserver`, takes the entry's scripts out with `DOMParser`, puts them back with the nonce, and allows no new script once the page is closed. A frame the app makes cannot know N, so it runs no script, and with no script there is no WebRTC. A lock added only after the write was not enough in Chromium, which snapshots a frame's policy when the frame is inserted, so frames the parser made from the entry kept the looser one. The runner checks the lock with a probe frame before it starts, and refuses where the probe's script runs. Measured with the lock: 0 hits from 16 kinds of frame (`srcdoc` made by the parser, by a classic and a module script and later, nested `srcdoc`, `about:blank` written into, `data:`, `blob:`, `object` and `embed` with `data:`, `javascript:` URLs, inline handlers, the app's own looser `<meta>` policy, nonce guesses), and the nonce read by none of the ways tried. The lock is a contract for apps, now in the bundle section: all code is in the entry's own `<script>` elements, inline `on…` handlers and scripts added after the start never run, and WebAssembly compiles. Chess complies. In WebKit, and in no other engine measured, `<link rel=preconnect>` still connected from the web runner, made by markup or by script and by name: the threats table and the install line now say so, pending the owner's decision on WebKit web clients.
