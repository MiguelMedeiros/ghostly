The broker now bounds `file` answers in bytes as well as in requests: reads go one at a time, and an app gets at most 16 MiB of file answers a second (a whole bundle's worth, `MINI_APP_LIMITS.fileBytesPerSecond`). A read that starts under that is answered whole; past it `file` is refused with `too-fast` until the second has gone. Within the 50 requests a second alone, an app with a 16 MiB file could make the page copy 800 MB a second.
