"Built-in apps" now says where the bundle is and when it is read. It is not kept in Ghostly's repository: a build reads it from the app's own repository at a pinned commit and tells it by the pinned digest. The build carries it as a file of the web app, kept by its worker so it is there offline, and a file of the Desktop application, read only when the person opens the app and checked whole against the pinned digest. A contact's card of the carried version opens from the build with no request, and a restored profile takes a built-in app's files from it. Chess 2.3.0 (`sequence` 4) is the first entry; the screens follow.
