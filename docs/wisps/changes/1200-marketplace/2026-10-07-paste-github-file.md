A pasted link to a file as GitHub shows it, `https://github.com/<owner>/<repo>/blob/<ref>/<path>` (or `/raw/<ref>/<path>`), naming a `.ghostlyapp` or `.json` file, is read at `raw.githubusercontent.com/<owner>/<repo>/<ref>/<path>`, with no request to `github.com`. It is the link a person copies when looking at the file, and it was refused as a host off the list. Any other `github.com` page (an issue, a profile, another file) is now refused as a GitHub page that holds no app (`github-link`), never with the words that GitHub is not a host the client reads.
