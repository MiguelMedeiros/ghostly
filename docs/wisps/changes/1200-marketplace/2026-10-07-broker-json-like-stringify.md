The broker now reads a request's arguments as `JSON.stringify` writes them: an object member that is `undefined` is left out, and `undefined` in an array becomes `null`, where it refused them before. Found by the end-to-end Chess test and in a live game: Chess saved and sent its game record spread with `d: undefined`, the broker refused it, and so no move was ever sent or kept. Chess now writes strict JSON itself, so it also runs on a client with the stricter broker. Any other value that is not JSON is still refused, and the `paired-app` frame stays strict JSON: no wire change.
