Accepted by the owner for release 1.2: the draft takes the family's number, 1200 (it was 12xx, and the old file and website address forward here), and is amended for the decisions of 2026-10-06. The chat frame is `paired-app` on the `apps/1` session capability, with at most 32 KiB of data per frame under the session's unchanged 60 KiB control-frame limit; play is live only in phase 1, never on the DHT or held, with the app's state kept per chat and a catch-up when the session comes back (`open` is sent again). The feature is called Apps, and the shared-services dialog is renamed Shared services. The default store is a repository of its own with an offline store key, and first-party mini-apps such as Chess are signed by a publisher key distinct from the store key. jsDelivr URLs must name a full commit. Desktop is in phase 1, with `app-*` windows on the `ghostly-app` scheme, and a problem its spike finds gets fixed; the extension, a bundle sent as a file, the store card, the crawler and the default index come later. The CLI in release 1.2 is `ghostly app publish`, `ghostly app verify` and `ghostly store sign`; `app init`, the SDK template and `catalog submit` come later. The app card is now defined in WISP 405, and a Test vectors section names the vector files, their layout and the cases each must hold.
