An app installed from a store's listing now updates only to the version that store's signed index lists, by `sequence` and digest (the owner's decision, 2026-10-08). A newer version at the publisher's `sources`, or at a listing URL that moved on (a repository's `HEAD`), waits until the store lists it, so the store's review covers what installs by itself. The client keeps the store's key with the installed app, reads only that store's listing for its updates and for a restored profile's files, takes only a bundle with the listed digest from its `urls`, and asks the app's `sources` only for revocations. A waiting update the store no longer lists is dropped, never installed. Installing from a listing also takes exactly the listed digest: a URL holding another version is skipped for the next, and none holding it is refused as `unlisted`. Installing another version by URL or from a card ends the pin, and so does removing that store, after which the app updates as one added by URL; an app added by URL or card updates as before.
