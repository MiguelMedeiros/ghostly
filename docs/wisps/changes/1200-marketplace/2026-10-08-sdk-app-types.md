The broker's typings ship as `@ghostlytools/sdk/app`: the `window.ghostly` API, the messages, the refusal codes, the limits and the manifest's type, with nothing imported at run time. The broker table now names every code the client answers with: `unknown-type` for a request type it does not answer, `bad-path` for a `file` path that is not a string of 1 to 1024 characters, `not-allowed` for `chat.send` without the `chat` permission or with the app opened alone, `not-open` before this side has opened the app in the chat, and `too-fast` and `too-large` for any request past 50 a second or 64 KiB. A later client may add a code, which an app reads as `failed`.
