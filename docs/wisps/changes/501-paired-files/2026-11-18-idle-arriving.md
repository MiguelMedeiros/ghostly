A `files/3` receiver also ends a taken file that is arriving (neither side has it paused) once no byte of it arrived for seven days of open sessions with its sender, as `expired` (`pf-refuse`), so a sender that stopped sending no longer keeps the room it would take here for good. Only the time a session was open counts: time with no session (closed, the app gone, either side away) does not, and every byte and every change of the file's state starts the count again. A paused file is never ended this way, and a taken file is still not ended on the sender's side. No new frame.
