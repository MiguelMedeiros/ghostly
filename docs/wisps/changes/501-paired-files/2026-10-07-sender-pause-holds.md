A sender's pause holds whatever the receiver answers. A file paused while its receiver's person had not decided yet went back to waiting for them when the receiver answered the paused offer with `pf-wait` `consent`, and it went as soon as they accepted. Now a `pf-wait` leaves a sender's pause alone, and a `pf-accept` that comes while the sender paused is answered with the paused offer again, so the receiver shows it paused by the contact. Nothing changes on the wire.
