A headless profile (WISP 1100) says no presence unless it opts in (the CLI's `daemonPresence` setting, off by default). Opted in, a running daemon says `p: "active"` while it runs, said again within every 10 minutes so it never turns `idle`; turned off, its next frame carries no `p`. When the daemon stops, its sessions end and presence with them. "Share when I'm online" off still keeps `p` out.
