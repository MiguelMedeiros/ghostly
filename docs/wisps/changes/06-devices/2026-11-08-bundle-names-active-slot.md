A backup of an enrolled profile also says which slot was active when it was made, as the device that made it knew it (`active` in the bundle's device set record, optional: an app from before neither writes nor reads it). When the turn record expired, the restore names that device, and a copy that takes over marks it active, so the takeover asks for its name. A bundle that names none names no device rather than the one in its first slot, which may be a device on standby.
