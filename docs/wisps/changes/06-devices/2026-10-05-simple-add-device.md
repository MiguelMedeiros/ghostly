Adding a device is one screen on the new device. Every route to a code (the camera opening the link, Join, "I already use Ghostly", "Add this device to another profile", a paste) ends on "Add this phone to <profile>" with the device's name and one button, in any profile: the page asks the engine first (`deviceEnrollReady`) and, where the profile holds something or is on standby, the button makes a new profile that goes on to the digits by itself. The ask-first "Add this device to another profile?" step is gone. The link may name the profile before the code (`#<profile>#ghostly1z…`), shown only, read by older apps as the bare code. The lock the person passed in the tab is handed across the new profile's start and the reload into the standby screen (a session-storage marker, once, 15 seconds). The active device shows where the enrollment stands under the QR code, including "A device is connecting" (`seen` on the inviter's waiting view) and the time left, with the password asked inline in the same dialog. On iOS 26 the app added to the Home Screen opens at the manifest's start page with storage of its own, whatever the address was in Safari, so a code opened there is scanned again in the app; the steps name the ⋯ menu and More, where newer iPhones keep Share and Add to Home Screen.
