Adding a device: the inviter now says that a second device is on its code in every case, also when the two opened the code before either had authenticated, and over WebRTC. Every device that reads a code writes the same one-time packet and the inviter reads only the last one written, so a device whose packet was replaced never reached it, and the screen with the digits said nothing of a second device. A joiner with WebRTC now always makes an offer (signed with its device signing key), puts its packet out again every 5 seconds while it has no session, and the inviter goes on reading that packet through the digits step and counts every further key that signs there. No frame and no record changed.
