"Remove this profile here" is now described, and offered on both screens of a device that is out of the set for good: `removed`, and `moving` with no `set-update` it can accept. It asks for the profile's name typed, deletes on this device what deleting a profile deletes (the namespace it runs on, its wallets' own storage, files, keys, forks and device record), and touches nothing on the network. The first profile, which cannot be deleted, stays on the list and opens empty, so the device can be added to a profile again. Before, the WISP named the button on the `removed` row only, and the app offered just "Add this device to my profile", which left the frozen copy where it was.
