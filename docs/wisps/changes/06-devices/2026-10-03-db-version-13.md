Brought up to date with dev after 1.0.3. `DB_VERSION` is now 13 with devices, a step with no change of the schema: 1.0.3 reads 12, so it never opens and starts a frozen copy. The files a frozen copy holds are kept by digest in the device record, so no index on the files store and no step of its own for it. A bundle with a device set has envelope version 3, since WISP 05's streamed bundle took 2; a light backup stays at 2 with its mark in the `profile` record, and one with a device set is 3 with the same mark. A handoff reads the Breez database name without claiming anything (`breezDatabaseInUse`) and deletes it with `dropBreezDatabase`, which in a handoff counts only a delete that succeeded.
