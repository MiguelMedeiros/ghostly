The device record keeps, beside `forks`, when each fork was kept (`forkKeptAt`, by fork name), written when Use here installs the new state beside the fork and taken off with the fork at Discard. Data and storage showed every fork as the same row, with the same Discard, so a device that kept two could not tell which one Discard deletes for good. Each row now says when it was kept, and so does its Discard. The field is optional and local to the device: an older build reads the record as before and leaves it alone, and a fork kept before it shows as an older copy.
