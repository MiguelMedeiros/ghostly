A tombstone makes a device `removed` only when the device it believes active signed it: the one its stored record names (itself, on the active device), or the other device of a handoff under way. A valid tombstone needs only `D` and one slot's key, so another slot could sign one too. Any other valid tombstone still stops the device, and leaves it `moving` whether it lists it or not. A device that was off waits there for the signed `set-update`. The device that was active keeps its copy, frozen, and starts a set of its own, which another slot's tombstone does not end. A `set-update` whose tombstone does not list the receiver ends it under the same rule.
