A `moving` device believes only the device its stored turn record names active. A record carried beside a `set-update` (`rec`, which earlier builds sent and took as proof of a handoff the receiver did not read) no longer moves that belief: a release the stored active device signed stays valid after it took the turn back and removed the device it handed it to, and the tombstone hides every later record. A device that did not read a handoff before the tombstone is added again, as one off across a takeover is. Frames that carry `rec` still read; it is ignored, and this build sends none.
