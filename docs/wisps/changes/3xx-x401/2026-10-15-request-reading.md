Reading the OpenID4VP request is built. A signed request takes ES256 and `x509_san_dns` only, and is refused for another host before its certificate is looked at; its chain is checked against Node's default trusted roots and a DNS name of the leaf, never its common name. An unsigned request's verifier is `origin:<origin called>`, and a `client_id` in it is ignored. The approval digest now also covers the token endpoint's origin, so approving a presentation never approves a token exchange to an endpoint the person did not see.
