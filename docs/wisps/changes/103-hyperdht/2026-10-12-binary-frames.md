HyperDHT frames are described (a 4-byte length word, at most 60 KiB, the preface first), and a frame whose length word has its top bit set is a binary message of the session (100). The CLI and a browser through a HyperDHT relay carry them, so `files/4` can be agreed there; the Desktop does not yet. An older app closes a stream on such a frame, so one is sent only under a capability both sides agreed.
