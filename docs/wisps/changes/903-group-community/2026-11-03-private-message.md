A pair payload may carry a request for a 1:1 chat and its answers, `{ "dm": … }` (in the core, no app sends or takes it yet), with the body and rules of a private group's `group-pair` ([902 § Private messages](../../902-group-mesh.md#private-messages)). It is stored and caught up like any pair payload. An app from before shows nothing, so with no `got` in 30 seconds the sender shows the invite to copy.
