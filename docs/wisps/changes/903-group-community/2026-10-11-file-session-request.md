A pair payload may carry a request for a file session and its refusal, `{ "gf": … }` ([503](../../503-group-files.md#asking-for-a-file-session); not built yet). Hubs relay it as any pair payload. The pair's edge opened for the transfer is the one case where two members who are not hub and member connect to each other, so each learns the other's network address; it carries no frame of the group and closes after the transfer.
