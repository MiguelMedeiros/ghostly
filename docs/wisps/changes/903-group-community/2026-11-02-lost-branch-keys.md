A key let in only on a branch that can no longer win (it drops an admin change the main branch holds, or parts before the window) is no longer answered or relayed to as a member: its `group-sync` gets the main branch's commits from where its branch parts up to the one that makes it lose, and nothing else. An app whose admission lost asks again at the link it was let in by. A branch that may still win is heard as before. No change on the wire.
