An application frame that is only a hint, a `group-have` ([503](../../503-group-files.md#who-holds-what)), is relayed and handed to the application like any frame but no longer kept in the store, handed in a catch-up, or remembered as a frame no edge took (§ Messages and catch-up). Every member that fetched a file said so to the group and every member kept that, so each file took up to one of the 256 stored places per member: in a community of 16, six photos fetched while a member was away cost it 40 of the 200 lines said meanwhile. Nothing changes on the wire; an app from before still keeps the ones it receives.
