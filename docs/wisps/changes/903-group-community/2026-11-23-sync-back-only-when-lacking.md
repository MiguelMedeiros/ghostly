§ How an answer goes: the answer to a member's `group-sync` ends with the answerer's own sync only when that member's sync names something the answerer lacks (another tip or picture tag, a secret it does not hold, a frame past what it has of a sender) or the answerer itself misses something (a gap in a sender's frames, a secret, the link's seed). Before, every answer carried one, so a hub answered each member's half-minute sync in an idle community with its own (5.4 KB at 48 members), and the member answered that with the link's seed again. Client policy, no wire change.
