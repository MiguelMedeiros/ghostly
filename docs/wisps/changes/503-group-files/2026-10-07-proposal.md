Proposal: a file or voice message in a group is announced as a group message carrying a sealed description (name, type, size, SHA-256, the voice, video or picture description of 501) under the author's signature, and its bytes go over `files/3` between two members, from any member that holds the file to any member that asks for it, never through hubs or the DHT. Up to 100 MiB a file; voice and files up to 8 MiB download by themselves; older apps show a fallback line.
