How a holder with no edge to the asker learns to open its side of a file session, which the profile left unsaid (§ Asking for a file session; not built yet). The asker first sends a signed `group-fetch` naming the holder and the message, through its hubs in a private group and as a pair payload sealed to the holder in a community. The holder checks it (roster, the message's epoch, the file, serving on, room for a session) and either opens its side for 30 seconds or answers a signed `group-want-no` the same way, without opening anything. Each side closes the session 60 seconds after its last transfer, or 30 seconds after starting when it never came up; an edge the topology comes to want stays. A file session is no edge of the group and carries no `group-have`. Only a download the person asked for opens one: a file session shows two members each other's network address, and the holder's serving setting gates its side. `paired-groups` version 7, since release 1.2 shipped 6.
