New section, Your own TURN server: the TURN server a profile names in Settings, Network (address, username and credential, refused when one is missing) is used after the built-in STUN servers by chats over WebRTC and by calls on every client, now including the Linux desktop's native calls, which gather until they have a relay candidate when one is set. The credential is never logged and a backup leaves it out; a restored profile asks for it again, and calls skip that server until then.
