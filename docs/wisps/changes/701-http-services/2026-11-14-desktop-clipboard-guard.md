On Desktop, the window for a contact's app runs the web's clipboard guard first in every frame, whether Hide my IP from contacts is on or not: `document.execCommand("copy")` and `"cut"` work only during the person's own input in it, and `"paste"` never ([On the web](../../701-http-services.md#on-the-web)). Every answer gets the guard's policy too, so the app's frames come from its own origin only and a `javascript:` URL is refused.
