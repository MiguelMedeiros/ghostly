On the web, a worker a contact's app makes from a `blob:` URL of its own runs `importScripts` and `eval` again: such a worker takes the page's policy, Trusted Types included, so the guard starts it from a script that makes a default policy passing every string on, then runs the app's ([On the web](../../701-http-services.md#on-the-web)). A `data:` worker, and one made from a blob of another window, of a worker or already revoked, still cannot.
