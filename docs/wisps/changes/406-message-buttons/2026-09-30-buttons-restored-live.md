The DHT floor and a hold carry a question without its buttons, and a later live copy under the same id is taken as the one already there. The sender's app now notes a question that went on the floor or into a hold and, once live with an app that lists `buttons/1`, sends its buttons again as one edit of the buttons alone (the next edit number, the same text, so no version and no edit mark). At most once per question, restarts included, through the edit queue (live only, the highest edit winning); none to a contact without `buttons/1`, since an app from before buttons would mark the question edited. Groups have no floor or hold: a handed-on copy without its card is completed by the author's whole copy.
