Relays: the browser build (web app, extension, CLI) takes up to five relays, where it took four, and Settings, Network up to five; the desktop takes as many. Its defaults are n0's four public relays then Ghostly's own, `https://iroh.miguelmedeiros.dev/`, written without the trailing dot (the tunnel in front of it answers the dotted name with 404). Iroh homes on the one with the lowest latency it measures, so the others are the fallback. An older build refuses five relays: an older Desktop or CLI that reads a profile which saved five in Settings gets no Iroh until it updates. No wire change.
