Relays: with no relay chosen, the desktop's own Iroh homes on n0's four public relays plus Ghostly's own, `https://iroh.miguelmedeiros.dev/` (`iroh-relay` 1.3 behind a Cloudflare tunnel). Iroh homes on the one with the lowest latency it measures, so the others are the fallback. Ghostly's relay is listed without QUIC address discovery, which does not cross the tunnel; relaying works. Measured from Brazil (2026-11-02, two browser-build endpoints on one machine): online in 0.4 to 0.9 s, paired handshake 0.34 s, about 52 ms per message and 3.4 MiB/s, against 1.0 s, 150 to 200 ms and 1.4 MiB/s through n0's `use1-1`. The browser build keeps n0's four, as its Iroh takes at most four relays.
