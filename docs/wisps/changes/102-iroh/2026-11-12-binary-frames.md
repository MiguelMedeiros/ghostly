The Desktop's Iroh carries binary messages, marked as HyperDHT's are (WISP 103 § Frames): the top bit of a frame's length word set, its length in the other 31 bits. So `files/4` is agreed between two Desktops on Iroh, and a file goes as its bytes, not as base64url text a third larger. The browser and CLI build reads text frames only and offers no capability that needs a binary message, so a session with it is unchanged.
