Relays: the desktop's own Iroh now takes the Iroh relays of Settings, Network, as the browser build does. With relays chosen, a desktop endpoint homes on them and still tries direct paths; with none it homes on n0's public relays as before, or on `GHOSTLY_IROH_RELAYS` (comma separated) where that variable is set, for tests and self-hosted relays. A standby desktop uses the copy of the relays in its device record. Found by the Linux Desktop bug hunt: a web page on a local Iroh relay and a desktop on n0's had no relay in common, and a link came up only when the desktop dialled the page's relay.
