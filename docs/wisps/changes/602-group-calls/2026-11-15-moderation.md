Moderation: the group's admin signs `POST <sfu>/sfu/group-moderate` (tag `"ghostly-sfu/1 moderate"`) to mute a member's microphone, camera or screen, allow it again, remove a member from the call with a ban, lift the ban, or read the room's state. The node checks the token request's checks 1 to 4, then that `k` is the roster's admin and the target is not `k`; the token route refuses a banned key and leaves a muted key's sources out; the state lasts until the call ends or the admin lifts it, across a node restart. With a test vector, a Security note (a call ban keeps the current call key until the next epoch; a group remove rotates it), and a pointer from Removal.
