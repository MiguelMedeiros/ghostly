The secret guard holds on `engine.call` too: `sendMessage`, `sendGroupMessage`, `editMessage` (their text and a card's) and `forwardMessages` (the stored messages it forwards) are refused (`confirm`) when the text looks like a recovery phrase, a private key or a Cashu token, unless the request says `"force": true` (`ghostly engine … --force`), as `chat.send`, `chat.edit`, `chat.forward` and `group.send` already were. Before, the raw engine path sent such text with no check.
