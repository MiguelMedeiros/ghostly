An agent turn's `messageId` is now an id this runtime makes (`t_` and 32 hex digits), and the turn's `id` ends in it: `agent.turn:<source>:<chat or group>:<messageId>`. Before, both carried the id the message is stored under, of which its sender chooses up to 64 characters, so words of a contact's could stand outside `untrusted`. That id is now `untrusted.messageId`. `send --reply`, `group send --reply`, `file send --reply`, `react`, `pin`, `forward`, `message delete`, `message details` and `button press` take a turn's `messageId` as they take a stored id. A bot that kept turn ids from before sees new ones for the same messages; `--cursor` and `--since` are unchanged.
