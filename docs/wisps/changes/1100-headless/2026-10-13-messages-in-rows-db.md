The headless store keeps the values of the engine's messages in `rows.db` (SQLite, through `node:sqlite` on Node 22.13 and newer) and only their keys and index entries in memory, with a snapshot of a new format that older releases refuse with their "last used by a newer version" message; a backup's store still holds every value inline, so any release restores it, and on an older Node the store keeps every value in its snapshot as before.
