`listen`, `events` and `chat history` take `--translate <lang>`: a message someone else sent in another language gets an optional `translation: {from, text}` (with `--turns`, `untrusted.translation`), made by the translation runtime in the data folder (`translation-runtime/<version>/`, `translation-models/<from>-<to>/`). Without the runtime the command says so on stderr and prints what it did before.
