Transport and Calls: the folder a socket goes in when the profile's path is too long for one is named as the CLI builds it: `ghostly-<hash>/` (`ghostly-calls-<hash>/` for calls) in `$XDG_RUNTIME_DIR`, else in the system temp folder (`$TMPDIR`, on macOS the user's own `/var/folders/…/T/`) when that one is the user's alone, else `/tmp/ghostly-<uid>-<hash>/`, `<hash>` the first 24 hex digits of the SHA-256 of the profile folder's path. The Calls section left out the temp folder. The daemon now removes that folder when it stops, and a call's when its last call ends, when nothing else is in it: it stayed behind, empty. No wire identifier, field or exit code changed.
