`usage send --all` checks `--wait` and `--timeout` once, before any chat (`bad_request`). Each chat's `error` in `chats` is `{code, message}`, as every other error is. When every chat refused, the call fails with `details.chats`: the shared code when the chats agree, `refused` otherwise. Before, a wrong `--wait` or `--timeout` came back once per chat as text, and a run where no chat took the card answered as if it had worked (exit 0).
