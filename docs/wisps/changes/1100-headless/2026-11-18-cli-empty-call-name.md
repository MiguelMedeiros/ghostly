Calls: an empty `<chat|call>` is refused by `call answer`, `call flush`, `call hangup` and `call pipe` (a usage error, exit 2) and by `call.answer|hangup|get|flush` on the socket (`bad_request`). Before, it read as left out, so `ghostly call hangup "$CALL"` with nothing in `$CALL` hung up, or declined, whatever call was on. Left out, the command still names the only call. No wire identifier, field or event reason was added.
