An encrypted profile (`profile-key.json`, WISP 04) is unlocked before the engine starts: the daemon and a one-shot with no daemon read its passphrase from `--passphrase-file` (a path or `/dev/fd/<n>`; the daemon's option), else `GHOSTLY_PROFILE_PASSPHRASE`, else a prompt on a terminal, else exit with a usage error and open nothing. `daemon --detach` and `daemon restart` check it first and hand it to the daemon on a pipe; `profile passphrase` rewraps the key; `profile backup` refuses an encrypted profile for now (Profiles and files).
