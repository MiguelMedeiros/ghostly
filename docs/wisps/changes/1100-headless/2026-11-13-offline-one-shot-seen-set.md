A one-shot that runs offline (a read such as `status` or `chat list`, or a change of this device only) no longer reads the whole seen set at its start: it reads it only once a history or a transfer changes while it runs, and then reports what changed as any start does. Until then it reports the changes of the chats and groups themselves (a rename, a removal), and a message that arrived while no process derived events is reported by the next start that reads the set. The set keeps a note per message active in the last 30 days, and reading it took each such command about 0.16 s and 56 MB more per 50,000 notes.
