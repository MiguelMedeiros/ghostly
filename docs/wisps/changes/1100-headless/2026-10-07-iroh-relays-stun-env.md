`GHOSTLY_IROH_RELAYS` gives the headless runtime its Iroh relays, as `GHOSTLY_PKARR_RELAYS` gives its Pkarr relays: the only ones while it is set, whatever the profile's `irohRelays` setting says. `GHOSTLY_STUN=0` leaves the apps' public STUN servers out of every WebRTC connection, chats and calls, keeping the profile's own `iceServers`. With both, `GHOSTLY_PKARR_RELAYS` and `GHOSTLY_HYPERDHT_BOOTSTRAP`, a private network or a test reaches nothing public; the CLI's own tests and the web e2e's headless bots now run that way unless `GHOSTLY_TEST_PUBLIC_NET=1`.
