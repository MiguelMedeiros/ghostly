`profile restore` compares the backup with every profile of the home before the restored profile takes its name, as the app does on one device (WISP 05 § Restoring on the same device): a backup that shares a chat's participation key (a chat key for an older chat) or the DID key with one is refused (`refused`, `details.reason: "same-profile"`, `details.profiles` naming them), because both would act as one person to contacts. `--copy` restores it anyway. A running profile is read from its files beside its daemon.
