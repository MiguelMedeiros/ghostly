The headless profile backup uses envelope version 2 of WISP 05: the store and the profile's files are written and read a piece at a time, and the file takes its name only once it is whole. `profile backup --no-passphrase` makes a backup that is not encrypted, by explicit choice only: with neither a passphrase nor the flag nothing is made, and with both it is refused. `profile restore` asks for no passphrase for such a backup and says how the file was protected. Backups made by earlier versions still restore.
