Light backups: a bundle can leave out the bytes of files over 1 MiB (voice messages over 4 MiB), chosen when it is made. Its `profile` record says so with `light` (the cut, and how many files and bytes it left out), and each file left out travels as its record alone, marked `leftOut`, so a restore shows it as not in this backup instead of as a file that can be saved. The headless CLI makes one with `--light`. The decision is no longer open.
