Wake-up push on a mention: a member shares its push subscription with each other member on their own edge (`group-wake`, a token per edge, `null` while the group is muted), and the author of a message wakes each member it names by key whose app is closed, with 401's content-free push; never for `@everyone`, one per member per 5 minutes and four per group a minute. Muting the group, or a member who held a token leaving the group, replaces the subscription, as for a chat. In a group on hubs only members that share an edge can wake each other.
