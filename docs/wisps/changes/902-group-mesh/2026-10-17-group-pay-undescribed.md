A `group-pay` note known only from a member it is not about (a payer's `sent` for a request the payee has not described, a payee's `paid` for a payment the payer has not) is kept but no longer shown in the group's history until the member it names describes it. Before, the claim's own amount and memo stood in for the missing description under that member's name, so a member could make another member appear to ask for, or send, a payment they never made. No wire format change.
